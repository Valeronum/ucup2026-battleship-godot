3. ПАПКА scripts/ (GDScript файли)
═══════════════════════════════════════════════════════════════════════════════

📁 scripts/
   │
   ├── 📄 constants.gd
   │   ┌────────────────────────────────────────────────────────────────────────┐
   │   │ Статичні константи гри:                                              │
   │   │ • BOARD_SIZE = 10 - розмір ігрового поля                              │
   │   │ • SHIPS_DEF - масив типів кораблів (лінкор 4x1, крейсер 3x2, ...)      │
   │   │ • in_bounds(r, c) - перевірка меж поля                                │
   │   │ • rc(r, c) - конвертація рядок/колонка в індекс                       │
   │   │ • rand_i(max) - генератор випадкових чисел                            │
   │   └────────────────────────────────────────────────────────────────────────┘
   │
   ├── 📄 ship.gd
   │   ┌────────────────────────────────────────────────────────────────────────┐
   │   │ Клас Ship (class_name Ship)                                            │
   │   │ Опис окремого корабля:                                                 │
   │   │ • size - розмір корабля (кількість палуб)                              │
   │   │ • id - унікальний ідентифікатор                                        │
   │   │ • hits - кількість влучень по кораблю                                   │
   │   │ • sunk - чи потоплений корабель                                        │
   │   │ • cells - масив координат клітинок корабля {r, c}                      │
   │   │ • place(r, c, vertical) - розміщення корабля на полі                   │
   │   │ • hit() - реєстрація влучення, повертає true якщо потоплено            │
   │   └────────────────────────────────────────────────────────────────────────┘
   │
   ├── 📄 board.gd
   │   ┌────────────────────────────────────────────────────────────────────────┐
   │   │ Клас Board (class_name Board)                                          │
   │   │ Опис ігрової дошки:                                                    │
   │   │ • grid - масив клітинок (ship_id, state, revealed, sunk)              │
   │   │ • ships - масив розміщених кораблів Ship                               │
   │   │ • _reset() - очищення та ініціалізація поля                             │
   │   │ • cell(r, c) - отримання даних клітинки                                 │
   │   │ • can_place(r, c, size, vertical) - перевірка можливості розміщення   │
   │   │ • place_ship(ship, r, c, vertical) - розміщення корабля               │
   │   │ • auto_place_all() - автоматична розстановка всіх кораблів              │
   │   │ • receive_shot(r, c) - обробка пострілу, повертає результат             │
   │   │ • area_attack(r, c) - авіаудар по 3x3 зоні                              │
   │   │ • radar_scan(r, c) - сканування 3x3 зони                                │
   │   │ • all_ships_sunk() - чи всі кораблі потоплені                           │
   │   │ • to_snapshot() / from_snapshot() - серіалізація стану                   │
   │   └────────────────────────────────────────────────────────────────────────┘
   │
   ├── 📄 ai.gd
   │   ┌────────────────────────────────────────────────────────────────────────┐
   │   │ Клас AI (class_name AI)                                                │
   │   │ Штучний інтелект суперника:                                            │
   │   │ • diff - рівень складності (easy/medium/hard)                         │
   │   │ • shots - словник вже зроблених пострілів                              │
   │   │ • hits - масив координат успішних влучень                              │
   │   │ • reset() - скидання стану AI                                         │
   │   │ • choose_shot(board) - вибір наступного пострілу                       │
   │   │ • _random_shot() - випадковий постріл                                 │
   │   │ • _hunt_shot(board) - полювання на вражений корабель                    │
   │   │ • _strategic_shot(board) - стратегічний постріл (hard режим)            │
   │   │ • report_result(r, c, result, ship) - звіт про результат пострілу        │
   │   └────────────────────────────────────────────────────────────────────────┘
   │
   ├── 📄 game_controller.gd
   │   ┌────────────────────────────────────────────────────────────────────────┐
   │   │ Клас GameController (class_name GameController)                        │
   │   │ Головний контролер ігрового процесу:                                   │
   │   │ • player_board / enemy_board - дошки гравця та суперника                 │
   │   │ • ai - об'єкт штучного інтелекту                                       │
   │   │ • turn - чий хід (player/enemy)                                       │
   │   │ • over - чи гра закінчена                                             │
   │   │ • moves, hits, misses - статистика гри                                 │
   │   │ • abilities - кількість доступних здатностей (радар, авіаудар)           │
   │   │ • start_new() - початок нової гри з авто-розстановкою                   │
   │   │ • start_new_with_board(board) - початок гри з готовою дошкою             │
   │   │ • player_shoot(r, c) - постріл гравця                                  │
   │   │ • use_radar(r, c) - використання радару                               │
   │   │ • use_airstrike(r, c) - використання авіаудару                        │
   │   │ • enemy_take_step() - хід суперника                                   │
   │   │ • to_snapshot() / from_snapshot() - збереження/завантаження гри         │
   │   └────────────────────────────────────────────────────────────────────────┘
   │
   ├── 📄 audio_manager.gd (AutoLoad)
   │   ┌────────────────────────────────────────────────────────────────────────┐
   │   │ Глобальний AudioManager - керування звуком:                           │
   │   │ • start_music(loop) - запуск фонової музики                            │
   │   │ • stop_music() - зупинка музики                                        │
   │   │ • play_sfx(name) - відтворення звукового ефекту                       │
   │   │ Доступні ефекти: click, shot, miss, destroy, win, lose                 │
   │   └────────────────────────────────────────────────────────────────────────┘
   │
   ├── 📄 storage.gd (AutoLoad)
   │   ┌────────────────────────────────────────────────────────────────────────┐
   │   │ Глобальний Storage - збереження даних:                                  │
   │   │ • save_json(key, value) - збереження JSON у user://                    │
   │   │ • load_json(key, default) - завантаження JSON                           │
   │   │ • clear(key) - видалення файлу                                          │
   │   │ Файли зберігаються в user://ucup2026_<key>.json                       │
   │   └────────────────────────────────────────────────────────────────────────┘
   │
   └── 📄 main.gd
       ┌────────────────────────────────────────────────────────────────────────┐
       │ Головний скрипт UI та ігрового циклу                                   │
       │                                                                        │
       │ Змінні налаштувань:                                                    │
       │ • settings - словник (difficulty, sfx, music, autosave)                 │
       │ • game - поточний екземпляр GameController                             │
       │ • selected_ability - вибрана здатність (radar/airstrike)                │
       │                                                                        │
       │ Змінні розстановки кораблів:                                           │
       │ • _placement_board - дошка для ручної розстановки                      │
       │ • _placement_buttons - кнопки сітки розстановки                         │
       │ • _placement_ship_buttons - кнопки вибору кораблів                      │
       │ • _placement_selected_def_index - індекс вибраного типу корабля          │
       │ • _placement_vertical - орієнтація корабля (вертикальна/горизонтальна)   │
       │ • _placement_hover_r/c - координати наведення миші                       │
       │ • _placement_ships_left - скільки кораблів кожного типу залишилось       │
       │ • _placement_next_id - наступний ID для корабля                         │
       │                                                                        │
       │ Основні функції:                                                       │
       │ • _ready() - ініціалізація UI, завантаження налаштувань                  │
       │ • _on_play() - початок нової гри (відкриває Placement)                  │
       │ • _start_placement() - ініціалізація екрану розстановки                 │
       │ • _build_placement_ui() - побудова сітки та кнопок кораблів              │
       │ • _on_placement_cell_pressed(r, c) - клік по клітинці розстановки        │
       │ • _try_place_ship(r, c) - спроба розмістити корабль                      │
       │ • _on_placement_ship_selected(i) - вибір типу корабля                     │
       │ • _on_placement_rotate() - обертання корабля                            │
       │ • _on_placement_auto() - автоматична розстановка                          │
       │ • _on_placement_clear() - очищення поля                                   │
       │ • _on_placement_start() - початок бою з ручною розстановкою              │
       │ • _start_game_with_placement() - запуск гри з _placement_board          │
       │ • _update_placement_board_ui() - оновлення відображення поля             │
       │ • _on_cell_pressed_enemy(r, c) - постріл гравця по ворожому полю         │
       │ • _enemy_turn_loop() - цикл ходів суперника                               │
       │ • _on_save_game() / _on_load_game() - збереження/завантаження гри        │
       │ • _end_game() - завершення гри, збереження історії                       │
       │ • _save_history() / _load_history() - робота з історією матчів            │
       │ • _refresh_history() - оновлення таблиці історії                          │
       │ • _unhandled_input(event) - глобальна обробка клавіш (R для обертання)   │
       └────────────────────────────────────────────────────────────────────────┘

6. ІГРОВА МЕХАНІКА
═══════════════════════════════════════════════════════════════════════════════

📌 ПРАВИЛА РОЗМІЩЕННЯ КОРАБЛІВ:
   • Кораблі не можуть торкатись один одного (в т.ч. по діагоналі)
   • Корабель повинен повністю вміщуватись у поле 10x10
   • Доступні типи: 4-палубний (1шт), 3-палубний (2шт), 2-палубний (3шт), 
     1-палубний (4шт)

📌 ІГРОВИЙ ЦИКЛ:
   1. Гравець розміщує кораблі вручну або автоматично
   2. Гра починається, хід гравця
   3. Постріл по ворожому полю
   4. Якщо влучено - ще один хід
   5. Якщо промах - хід суперника (AI робить постріли автоматично)
   6. Перемога/поразка - збереження в історію

📌 ЗДАТНОСТІ (ОБМЕЖЕНІ ВИКОРИСТАННЯ):
   • Радар - показує наявність кораблів у 3x3 зоні (1 раз за гру)
   • Авіаудар - атакує 3x3 зону одним пострілом (1 раз за гру)

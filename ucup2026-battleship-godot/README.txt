README – BattleBugs: Picnic

1. Опис проєкту
   Гра «BattleBugs: Picnic» розроблена для UCUP-2026 Game Jam у рамках Харківського університетського кубку.
   Це повноцінний однокористувацький проєкт проти AI з двома унікальними механіками (твіками):
   Радар 3×3 та Великий камінець 3×3. Реалізовано три рівні складності AI, автозбереження, журнал історії матчів та повноцінний звуковий супровід.

2. Склад архіву
   • index.html                – основний файл гри (відкривати для запуску)
   • css/ (вбудовано в HTML)   – стилі інтерфейсу
   • js/ (вбудовано в HTML)    – ігрова логіка, AI, збереження, звук
   • assets/images/            – згенеровані ігрові зображення (фон меню, фон гри, іконки здібностей)
   • assets/sounds/            – згенеровані звукові ефекти та музика
   • GDD.txt                   – Game Design Document
   • README.txt                – цей файл

3. Системні вимоги
   • Операційна система: Windows 10 / Windows 11 (Win64)
   • Браузер: Google Chrome, Microsoft Edge, Mozilla Firefox (остання версія)
   • Додаткове ПЗ: не потрібне
   • Права адміністратора: не потрібні

4. Інструкція з запуску
   1. Розпакуйте ZIP-архів у будь-яку папку на ПК.
   2. Відкрийте папку проєкту.
   3. Подвійним кліком відкрийте файл index.html.
   4. Гра запуститься у вашому браузері за замовчуванням.
   5. Для повноцінного звукового супроводу натисніть будь-де на екрані меню (для активації аудіо в браузері).

   Альтернативний запуск:
   — Клікніть правою кнопкою на index.html → «Відкрити за допомогою» → оберіть Chrome/Edge/Firefox.

5. Коротке керівництво
   • Натисніть «Швидка гра» у головному меню для старту.
   • Клікайте по клітинках правого поля («Поле противника»), щоб стріляти.
   • При влучанні ви отримуєте додатковий хід; при промаху хід переходить до AI.
   • Використовуйте здібності (ліворуч): «Радар 3×3» — сканує область, «Великий камінець 3×3» — атакує область.
   • У налаштуваннях можна змінити рівень складності AI (Легкий / Середній / Складний).
   • Гру можна зберегти та завантажити під час партії кнопками внизу екрану.

6. Структура ігрового процесу
   Мета: першим знищити всі кораблі супротивника (20 палуб).
   Склад флоту: 1 лінкор (4), 2 крейсери (3), 3 есмінці (2), 4 катери (1).

7. Відомі обмеження
   • Мережевий режим відсутній (тільки проти AI).
   • Для роботи звуку потрібен сучасний браузер із підтримкою Web Audio API.

8. Контакти / Автор
   Розроблено для UCUP-2026 Game Jam командою “Шаума (з малиною)”.
